# Speech Session Interactive Concept

Interactive concept — fictional demonstration data

Original demonstration work by Forson & Co. Role: product concept and workflow coordination. This self-contained HTML/CSS/JavaScript preview demonstrates a shared-device card-turn activity with one to four sample players, multiple goals per player, avatar changes, two visual styles, sample card formats and in-memory deck creation.

It is not paid client work, a clinical product or a completed React/Node application. The sample prompts and goal labels are fictional interface examples, not clinical guidance. There is no backend, account system, persistent storage, billing, remote multiplayer or clinical assessment.

Open `index.html` in a modern browser. Use fictional content only. Changes exist in page memory and disappear on reload. The preview includes no analytics, external dependencies, API calls, contact forms or off-platform contact methods. Static hosting providers may retain ordinary access logs.
